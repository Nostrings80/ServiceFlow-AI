# Cybersecurity Platform (Working Title)

Cloud-delivered cybersecurity platform: endpoint protection, cloud
workload protection, identity threat detection & response, data
protection, threat intelligence, and managed detection & response (MDR)
with human-led threat hunting.

See [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) for the technical
architecture, component breakdown, technology stack recommendations, and
open decisions.

No implementation exists yet — this repository currently holds the
architecture design only.
